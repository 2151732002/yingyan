自动化 AI 协议测试使用本机 HTTP 替身，验证 Responses 严格 JSON Schema 请求、最新完整草稿、近期消息历史、结构化回复与上游错误脱敏，不消耗真实额度。浏览器多轮测试使用协议替身测试界面，保存调用实际 Java 接口。

真实联调：使用用户已经配置在本机私有 `.env` 的 `deepseek-flash`，仅在独立 QA 数据库创建“雨夜咖啡馆”测试故事。完成两个成功轮次（初稿→保留人物与场景并修改结局）、保留 4 条对话消息、显式保存为 V2；发送过程中正式剧本仍为 V1 空文档。总共调用 3 次，其中首次第二轮返回无法解析的 JSON，验证上一轮草稿和待发送要求均保留，手动重试后成功。没有自动重试，没有修改用户正式剧本。没有完成真实 OpenAI 线上调用。

对话界面额外检查：1440px 桌面双栏，768/390/360px 的弹窗和发送/保存控件不被裁切，手机可切换剧本预览。新增截图中的人物和对话均为自构造示例，未上传用户剧本或密钥。

解析兼容修复：用户自行重试后，安全诊断捕获模型正文不是 JSON 对象，却被旧代码强制解析的情况。新增测试覆盖普通中文讨论保留、工作草稿不变且不能制造正式修订、多段 `output_text` 合并、BOM、损坏 JSON 仍拒绝，以及诊断不泄露正文/密钥。仅用虚构示例做额外模型探测，没有由助手自动重放用户现有剧本。
