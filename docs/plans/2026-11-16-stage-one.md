# 映言第一阶段实施计划

**Goal:** 交付独立可运行的中文剧情创作工作台，代码提交到用户的 yingyan 仓库。

**Architecture:** Next.js 同源代理 Spring Boot；MyBatis/MySQL 保存账号、项目 JSON 文档和不可变修订。图片保存在后端私有目录，OpenAI 文本规划是独立可配置适配器。

**Spec:** docs/design.md。用户已确认本阶段实现，按本会话顺序执行。
